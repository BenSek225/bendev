# BenDev - Portfolio

Portfolio professionnel de Y. Bienvenu Sekongo, développeur web et mobile fullstack basé à Abidjan, Côte d'Ivoire.

## 🚀 Technologies

- **Framework**: Next.js 16.3 (React 19)
- **Styling**: Tailwind CSS 4.3
- **Animations**: Framer Motion
- **Smooth Scroll**: Lenis
- **Language**: TypeScript

## 📦 Installation

```bash
npm install
```

## 🛠️ Développement

```bash
npm run dev
```

Ouvrir [http://localhost:3000](http://localhost:3000) dans votre navigateur.

## 🏗️ Build

```bash
npm run build
npm start
```

## 📁 Structure du projet

```
bendev/
├── app/              # Pages et routes Next.js
├── components/       # Composants React réutilisables
├── data/            # Données du site (projets, informations)
├── lib/             # Utilitaires et helpers
└── public/          # Assets statiques (images, icônes)
```
